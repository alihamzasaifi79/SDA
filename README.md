# Society Management System (Java Swing)

A desktop-based Society Management System built in Java using Swing GUI.


## Requirements

-   Java JDK 8 or higher (Recommended: 17)

## How to Run

1.  Compile:

javac com/society/main/\*.java

(If error, use:) javac --release 8 com/society/main/\*.java

2.  Run:

java com.society.main.Main
